# Course design

## 目的

未知の LLM 技術に出会ったとき、資料・コード・実験から理解を作れるようになることが目的です。

> Question → Search/Read → Trace → Predict → Experiment → Interpret → Explain → New Question

診断の観点は Explain / Trace / Predict / Interpret です。各週を完全理解するまで止まらず、約70%の理解で次へ進み、再登場した概念を更新します。

## 負荷

- Core: ミーティング込み約3時間。次週に必要な最低限。
- Standard: 合計5–8時間の通常ルート。
- Deep Dive: 余力がある場合だけ。未実施でも次週へ進める。

週末 meeting は60–75分を目安に、共有、相互質問、講師による誤解修正を行います。試験にはせず、毎週のスライドも要求しません。
