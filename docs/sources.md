# Sources

教材本文は転載せず、原典と読む範囲を示します。リンクは 2026-09-03 に到達確認しました。

- [Hugging Face LLM Course 日本語版「トークナイザー」](https://huggingface.co/learn/llm-course/ja/chapter2/4): Pre-Weekでは、はじめに、単語ベース、文字ベース、サブワード、エンコーディング、デコーディングを導入に使う。
- [言語処理100本ノック 2025 第5章](https://nlp100.github.io/2025/ja/ch05.html): 問49「トークン化」は、短い導入と観察の後に使う確認演習とし、API利用は要求しない。
- [同 第10章](https://nlp100.github.io/2025/ja/ch10.html): 問90、91、93はPre-Week、問94、95はWeek 4の確認演習として使う。問98、99はWeek 4 Optionalとする。
- [Let's build GPT: from scratch](https://www.youtube.com/watch?v=kCc8FmEb1nY): Week 1。timestamp は目安。
- [Hugging Face LLM Course, Tokenizers](https://huggingface.co/learn/llm-course/chapter6/1): Week 2 は Introduction、BPE、block-by-block の必要箇所。
- [Training a causal LM from scratch](https://huggingface.co/learn/llm-course/chapter7/6): Week 2 は Preparing the dataset と Training loop の考え方だけ。大規模 download は行わない。
- [Attention Is All You Need](https://arxiv.org/abs/1706.03762): Abstract, Fig. 1, §3.2, §3.2.1。
- [RoFormer](https://arxiv.org/abs/2104.09864): Abstract, §3.2.2。
- [RMSNorm](https://arxiv.org/abs/1910.07467): Abstract, §3。
- [GLU Variants Improve Transformer](https://arxiv.org/abs/2002.05202): Abstract, §2。
- [GQA](https://arxiv.org/abs/2305.13245): Abstract, Fig. 1, §2。
- [FlashAttention](https://arxiv.org/abs/2205.14135): Abstract と Fig. 1。exact attention の IO-aware 実装という位置付けのみ。
